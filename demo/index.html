📦 ReproPack v0.2 · browser extension

“It’s broken” → a report worth filing

Record what happened, capture the errors, and ReproPack organizes it into a clean Markdown report — then files it to GitHub, Jira or Slack. It never invents a cause.

▶ Try the live demo ⭐ GitHub repo
CAPTURE

⏺ Record + 📸 screenshot

Timeline of clicks and navigations, console errors, every request, and a screenshot or short clip.

ORGANIZE

🧠 Evidence only

Template report by default, optional BYO-key AI polish, heuristic severity suggestion with its reasons.

VERIFY

🔍 Duplicate check

Fingerprints errors and page patterns to surface reports you already saved — before you file again.

FILE

🚀 One click out

GitHub issue, Jira issue (ADF or wiki), Slack message, or your own webhook — plus Markdown, Jira wiki and HAR-lite exports.
